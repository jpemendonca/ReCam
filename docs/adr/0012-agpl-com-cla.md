# ADR 0012: AGPL-3.0 com CLA

- Data: 2026-09-24
- Estado: aceita
- Origem: decisão inicial, `SPECS.md` 12

## Contexto

O projeto é open source e não quer ser fechado e revendido como serviço por terceiros. Ao mesmo
tempo, o autor quer poder ajustar a licença no futuro.

## Decisão

Licença AGPL-3.0, com CLA para contribuições.

## Consequências

- Quem oferecer o ReCam como serviço precisa publicar as mudanças.
- Contribuidores assinam o CLA, o que mantém a licença ajustável.
